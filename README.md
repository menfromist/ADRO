# ADRO — 광고 로드 (Ad Road)

> 빠른 길 대신, 걸을수록 쌓이는 길.

광고가 밀집해 있고 잘 보이는 거리를 이동 경로로 안내하고, 사용자가 그 경로로
이동하면 캐시워크처럼 걸음·노출 보상을 지급하는 **맥락 기반 맞춤형 경로**
프로젝트입니다. '그늘길' 앱의 "빠른 길 대신 맞는 길" 발상을 광고 생태계와
연결했습니다. 자세한 기획은 [docs/concept.md](docs/concept.md) 참고.

- **사용자**: 허용한 범위 안에서만 우회하고, 걸음 + 광고 노출 포인트를 받는다
- **광고주**: 실제 도보 노출(CPE) 기준으로만 비용을 낸다
- **알고리즘 보장**: 광고 로드는 사용자가 정한 우회 예산을 절대 넘지 않고,
  그 안에 더 나은 길이 없으면 최단 경로와 동일하다

## 데모 실행

빌드 없이 브라우저에서 바로 열립니다.

```
web/index.html
```

지도에서 출발지·도착지를 클릭하면 **최단 경로**(회색 점선)와
**광고 로드**(주황 실선)를 비교하고, 거리·시간·걸음·광고 노출·예상 리워드를
나란히 보여줍니다. 허용 우회율 슬라이더로 우회 예산을 조절할 수 있습니다.

데모 지역은 두 가지입니다.

- **서울 용산 — 실제 데이터** (기본): OpenStreetMap 실제 도로망 위에
  서울시 버스정류소(버스쉘터·역 미디어보드 = 실제 옥외광고 매체) 23곳을
  광고 지점으로 배치. 삼각지역·신용산역·이촌역·녹사평역 등 실명 지점.
- **가상 도심 — 시뮬레이션**: 광고 밀집 거리 3곳을 가진 시드 고정 격자 도시.

## 실데이터 파이프라인

```
npm run build:data   # data-src/* → web/data/yongsan.js
```

| 데이터 | 출처 | 라이선스 |
|---|---|---|
| 용산 도로망 | OpenStreetMap (openlayers/openlayers 예제 추출본) | ODbL 1.0 |
| 버스정류소 위치 | 서울 열린데이터광장 (Just-Kaggle/labs 미러) | 공공데이터 |

파이프라인은 GeoJSON 도로를 교차점 기준으로 분할해 보행 그래프를 만들고
(최대 연결 요소만 유지), 정류소를 가시권(160m) 안 도로에 광고 매체로
부착합니다. 같은 광고가 여러 간선에 보여도 노출 정산은 광고 id 기준 1회입니다.
자세한 출처는 [data-src/README.md](data-src/README.md) 참고.

## 구조

```
src/graph.js       도로 그래프(폴리라인 지오메트리) + 다익스트라 (브라우저/Node 겸용)
src/adroad.js      광고 로드 라우팅 — 우회 예산 내 광고 노출 최대화 (β 스윕)
src/rewards.js     리워드 모델 (걸음 보상 + CPE 광고 노출 보상, 일일 상한)
src/demo-city.js   시드 고정 가상 도심 생성기 (광고 밀집 거리 3곳)
src/load-city.js   직렬화된 실데이터 → 그래프 로더
scripts/           실데이터 빌드 파이프라인
data-src/          원본 데이터 (OSM 도로망, 서울시 버스정류소)
web/               인터랙티브 데모 (canvas, 의존성 없음)
test/              node:test 기반 엔진·실데이터 테스트
docs/concept.md    서비스 기획 문서
```

## 라우팅 방식 요약

최단 경로 대비 `허용 우회율`을 넘지 않는 경로 중 광고 노출 가치가 최대인
경로를 찾습니다. 제약 최단 경로는 NP-hard이므로, 간선 비용을
`거리 − β × 광고가치`로 두고 β를 스윕하는 다익스트라 근사를 사용합니다.
간선 점수 함수만 바꾸면 그늘길·안심길 같은 다른 맥락 프로파일로 확장됩니다.
