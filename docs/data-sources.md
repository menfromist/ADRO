# 데이터 소스 전략 — 믿을 수 있고 안정적인 정보처

데모에 지금 쓰는 데이터와, 실서비스 단계에서 옮겨갈 공식 정보처를
신뢰 등급별로 정리한다.

## 등급 기준

- **1급 (공식 원천)**: 정부·공공기관이 직접 발행. API 키만 있으면 정기 갱신 수신 가능
- **2급 (공식 파생)**: 공식 데이터의 커뮤니티 미러·가공본. 원천 추적 가능, 버전 고정 필요
- **3급 (크라우드소싱)**: OSM 등. 품질은 지역별 편차가 있으나 라이선스가 자유롭고 전세계 커버

## 2급 — 지금 데모가 쓰는 소스 (버전 고정으로 안정화)

GitHub·패키지 레지스트리만 접근 가능한 현재 개발 환경에서 쓰는 미러.
`data-src/MANIFEST.json` 에 **커밋·체크섬을 고정**해 두었고,
`npm run verify:data` 가 원본 오염·변경을 빌드 전에 잡아낸다.

| 파일 | 미러 | 원천 |
|---|---|---|
| seoul-roads.pbf | anvaka/index-large-cities (gh-pages) | OSM Overpass |
| roads-seoul.geojson | openlayers/openlayers 예제 | OSM overpass-turbo |
| 버스정류소·지하철역 CSV | Just-Kaggle/labs | 서울 열린데이터광장 |

## 3급 — OSM 직접 수집 (커버리지 확장용)

- **Overpass API** (`advertising=billboard/screen/poster_box` 태그): 전세계
  옥외광고물 위치를 키 없이 수집 가능. 한국은 태깅 밀도가 낮아 보조용
- **Geofabrik / BBBike 추출본**: 서울 전체 PBF 정기 스냅샷

## 마이그레이션 계획

1. **지금 (데모)**: 2급 미러 + 매니페스트 고정 — 재현 가능, 무결성 검증
2. **베타**: 공공데이터포털·열린데이터광장 API 키 발급 → 야간 배치로
   `data-src/` 자동 갱신 (파이프라인은 그대로, 소스만 교체)
3. **정식**: 지자체 옥외광고물 관리대장 + 매체사 인벤토리 계약 →
   광고 지점이 '실제 판매 가능한 광고면'으로 전환, CPE 정산 개시

핵심 설계: `scripts/build-real-data.js` 의 지역 정의는 소스 로더만 갈아끼우면
되므로, 1→2→3단계 전환에서 엔진·데모 코드는 바뀌지 않는다.
