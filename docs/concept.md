# ADRO — 광고 로드 (Ad Road)

> 빠른 길 대신, 걸을수록 쌓이는 길.

## 1. 한 줄 요약

광고가 밀집해 있고 잘 보이는 거리를 이동 경로로 안내하고, 사용자가 그 경로로
실제로 이동하면 걸음·노출 보상을 지급하는 **맥락 기반 맞춤형 경로** 서비스.

'그늘길'(햇빛 피하는 산책 지도) 앱이 증명했듯, 지도 앱의 경쟁력은 이제
"가장 빠른 길"이 아니라 "지금 나에게 맞는 길"에서 나온다. ADRO는 그 축을
광고 생태계와 연결한다.

## 2. 3자 가치 교환

| 주체 | 주는 것 | 받는 것 |
|---|---|---|
| 사용자 | 약간의 우회 (본인이 허용한 범위 내) | 걸음 포인트 + 광고 노출 포인트 |
| 광고주 | CPE(노출당 비용) 광고비 | 검증된 실제 도보 노출, 매장 앞 유동인구 |
| 플랫폼 | 경로 추천·노출 검증·정산 | 광고비 중개 수수료 |

핵심 차별점: 온라인 광고의 "노출"은 스크롤 한 번이지만, 광고 로드의 노출은
**사람이 실제로 그 거리 앞을 걸어서 지나가는 것**이다. 옥외광고(OOH) 업계가
증명하지 못하던 노출 검증을 GPS 이동 데이터로 해결한다.

## 3. 경로 설계 원칙

1. **우회는 항상 사용자가 통제한다.** 허용 우회율(기본 30%)을 사용자가 정하고,
   경로는 그 예산을 절대 넘지 않는다. 예산 안에서 광고 노출 가치를 최대화한다.
2. **최단 경로보다 나쁠 수 없다.** 예산 안에 더 나은 길이 없으면 그냥 최단
   경로를 준다 (알고리즘상 보장됨 — 테스트로 검증).
3. **맥락 프로파일은 플러그인이다.** 간선 점수 함수만 바꾸면 광고 로드 외에도
   그늘길(그늘 점수), 안심길(조명·CCTV 점수), 계단 없는 길 등으로 확장된다.

## 4. 라우팅 알고리즘

- 도로망을 무방향 그래프로 두고, 각 간선에 광고 목록(노출 가치)을 붙인다.
- 목표: `length(경로) ≤ (1 + 허용우회율) × 최단거리` 조건에서 광고 가치 최대화.
- 제약 최단 경로는 NP-hard이므로 라그랑주 완화 방식의 근사를 쓴다:
  간선 비용을 `거리 − β × 광고가치`(하한 5% 클램프)로 두고 β를 0부터
  상한까지 스윕하며 다익스트라를 반복, 예산을 만족하는 후보 중 광고 가치가
  최대인 경로를 채택한다.
- 데모 규모(수백 노드)에서는 실시간이며, 실서비스 규모에서는 지역 분할 +
  캐싱으로 확장한다.

## 5. 리워드 모델 — 2단계 전략

실제 광고주와의 CPE 계약은 시간이 걸린다. 그래서 보상은 두 단계로 간다.

**1단계 (지금): 가상 재화 — AD코인 + 배지.** 현금성 부담과 정산 리스크 없이
적립 루프를 먼저 검증한다. 코인은 앱 내 재화(스킨·부스터·랭킹)로 쓰고,
배지는 수집·과시형 동기를 만든다. 이 단계의 적립 데이터가 곧 광고주 영업
자료(예상 노출량 실측치)가 된다.

**2단계 (광고주 계약 후): 실비 정산.** 적립 구조는 그대로 두고 광고별
가치(코인 단가)만 광고주 CPE 단가로 교체한다. 기존 사용자 코인은 전환
비율을 공지하고 승계한다.

| 항목 | 기본값 | 근거 |
|---|---|---|
| 걸음 코인 | 걸음당 0.05코인 | 캐시워크류 통상 수준 |
| 광고 노출 코인 | 광고별 2~18코인 | 추후 광고주 CPE 단가로 교체 |
| 일일 상한 | 500코인 | 어뷰징 억제 + 코인 인플레이션 방지 |

### 배지 (경로 성과 기반, `src/badges.js`)

| 배지 | 조건 |
|---|---|
| 미디어 헌터 | 한 번의 이동으로 광고 10곳 노출 |
| 디지털 컬렉터 | 역 미디어보드·디지털 매체 3곳 노출 |
| 만보 로더 | 한 경로에서 8,000걸음 |
| 동네 탐험가 | 지역 광고 매체의 30% 커버 |
| 코인 러시 | 한 경로에서 300코인 적립 |

실서비스에서는 누적형(연속 7일, 누적 10만 걸음)과 지역 시즌제(성수 시즌1)로 확장한다.

### 부정 적립 방지

- GPS 속도 검증: 도보 범위(1~7km/h)를 벗어난 구간은 미정산
- 경로 이탈 감지: 광고 지점 반경 통과가 확인된 노출만 정산
- 광고별 1인 1일 1회 정산 (왕복 반복 어뷰징 차단)
- 일일 총 적립 상한

### 광고주 정산 (CPE)

노출 1건 = "검증된 사용자 1명이 해당 광고 앞 도보 통과 1회".
지점별 시간대 가중치(출퇴근/점심 프리미엄)와 타겟 세그먼트 매칭 시 단가 상향.

## 6. 노출 모델

옥외광고의 노출은 "그 간선 위를 걷는 것"이 아니라 "가시권 안을 지나는 것"이다.
그래서 광고 매체는 가시권(현재 160m) 안의 인접 도로 여러 개에 부착되고,
경로 점수와 리워드 정산은 광고 id 기준으로 중복 제거해 1회만 집계한다.
실서비스에서는 매체 유형별 가시거리(쉘터 30m, 대형 빌보드 150m+)와
방향성(단면/양면)을 반영해 정교화한다.

## 7. 로드맵

1. **MVP (완료)** — 라우팅 엔진 + 리워드 모델 + 웹 데모 (가상 도심)
2. **실데이터 1차 (완료)** — 서울 용산 실제 도로망(OSM) + 서울시 버스정류소
   기반 광고 매체 23곳. `scripts/build-real-data.js` 파이프라인으로 재현 가능
3. 커버리지 확대 (Overpass API로 지역별 도로망·`advertising=*` 태그 수집),
   실제 옥외광고물 관리대장 연동, 모바일 앱
4. 노출 검증 파이프라인 (GPS 로그 → 노출 이벤트 → 광고주 대시보드)
5. 맥락 프로파일 확장: 그늘길·안심길·상권 탐방 코스, 프로파일 혼합 가중치
